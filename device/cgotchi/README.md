# Hey Tattva on the Cheeko Gotchi

Firmware for the Cheeko Gotchi v1.2 (ESP32-S3, 8 MB OPI PSRAM, 240x296 ST7789, CST810 touch, ES8311 speaker,
LIS2DH12 accelerometer). Pin map and quirks come from the board's SKILL.md in
github.com/ALTIO-AI-PRIVATE-LIMITED/cheeko-gotchi.

**Install:** https://heytattva.vercel.app/flash/cgotchi (Chrome/Edge on a laptop, USB-C data cable).

## What it does
- **Reels (tattvas 1, 2, 4, 6, 8):** The mirror city, The seed (a seed grows into a tree and back), The lamp in the
  pot, The eclipse (the moon covers the sun, then it shines again), The dream of roles (one light, many roles). Each
  has a 30 s music bed (sitar, tanpura, tabla from the site's renders) and the singer's recitation
  (streamed live from `/api/tts?v=N&fmt=pcm&voice=singer&sv=2`, again 5 s after it ends). The verse line follows the voice. Swipe up/down = next/previous,
  tap = pause, swipe right = back. Without Wi-Fi: music only.
- **Rock:** streams `/api/music?v=N&fmt=pcm&mix=1`: the server mixes the app's rock band track with the singer's
  rock voice (rock vocal chain, band ducking) into one 16 kHz WAV (`X-Voice-Start`/`X-Voice-Len` headers place the
  verse line), and the device plays it live and loops it. Fire stage, equaliser, prev/next, pause.
- **Streaming, nothing stored:** the voice and the rock track are streamed through a 12 s ring buffer in PSRAM
  (playback starts after 0.75 s); no FFat use. Wi-Fi is needed for them; the beds and games work offline.
- **Games (45 s each):** Mirror Letters (t1: tap the letter or its reflection), Grow the Seed (t2: tap the rising
  seeds in order; the tree grows with each word), Lamp Tilt (t4: tilt or drag the light to the letter), Eclipse (t6:
  letters circle the sun; the moon hides them), Dream Cards (t8: a 3x3 memory grid; a peek at the start). Key word =
  double points, wrong letter costs points. Best scores are saved.
- **Keys:** middle = back (hold 5 s = forget Wi-Fi), side keys = volume. Settings: volume, Wi-Fi, QR to the site.
- **Wi-Fi:** like the Waveshare build: hotspot `HeyTattva-Setup`, setup page at 192.168.4.1, saved creds.

## Files
```
HeyTattvaCG/HeyTattvaCG.ino  board layer: ST7789 over SPI (only changed rows are sent), touch mapping, keys, tilt, prefs
HeyTattvaCG/ui.h             all screens, the five reels, five games and the Rock stage, plain C++ (shared with the simulator)
HeyTattvaCG/gfx.h            240x296 canvas, 4-bit text masks, yantra, QR
HeyTattvaCG/audio.h          mixer task: bed + streamed voice, or the streamed rock mix; sfx; HTTPS streaming into a ring buffer
HeyTattvaCG/net.h            Wi-Fi + captive portal (same as the Waveshare build)
HeyTattvaCG/assets.h         GENERATED by tools/pack_cg.py (text rendered with the site fonts)
HeyTattvaCG/beds.h           GENERATED: the five music beds, IMA-ADPCM 16 kHz
tools/gen_cg.mjs, pack_cg.py render + pack assets: node tools/gen_cg.mjs; python3 tools/pack_cg.py b1.pcm b2.pcm b4.pcm b6.pcm b8.pcm
sim/sim.cpp                  PC simulator: renders every screen to PPM and runs touch + game tests
```

## Build
```
arduino-cli compile --fqbn "esp32:esp32:XIAO_ESP32S3:PSRAM=opi,PartitionScheme=tinyuf2_noota" --export-binaries HeyTattvaCG
cd sim && g++ -O2 -std=c++17 -I../HeyTattvaCG sim.cpp -o sim -lz && ./sim out
```
After a firmware change, trim the merged image (strip trailing 0xFF) into `flash/cgotchi/heytattva-cg.bin`.
The installer does not erase, so the TinyUF2 recovery bootloader at 0x410000 stays.

Not yet tried on a real board: if touch is off, recalibrate the mapping in `touchRead()`; if the light moves the
wrong way when tilting, flip the signs in `accelRead()`.
